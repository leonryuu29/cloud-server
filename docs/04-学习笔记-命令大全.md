# 学习笔记 · 从零到一用过的命令（复习用）

> 按我们实际做过的顺序整理。`#` 后面是解释。服务器是 Ubuntu 24.04，用户 root。

---

## 1. 连上服务器
```powershell
ssh root@<服务器公网IP>          # 用密码登录（最开始的方式，Termius 也是这个原理）
ssh ecs                          # 配好密钥 + 别名后，一个词就能登录
exit                             # 退出服务器
```
**SSH 密钥登录是怎么回事**
```powershell
ssh-keygen -t ed25519                         # 在电脑上生成一对钥匙：私钥 id_ed25519（自己留着）+ 公钥 id_ed25519.pub（给服务器）
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh root@<服务器公网IP> "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
                                              # 把公钥追加到服务器的 authorized_keys（「哪些钥匙能开门」）
```
电脑上的 `C:\Users\1\.ssh\config` 写了别名：
```
Host ecs
    HostName <服务器公网IP>
    User root
    IdentityFile ~/.ssh/id_ed25519
```
- 私钥 = 钥匙，谁拿到谁就能登服务器，**别外传 `.ssh` 文件夹**
- 安全组（阿里云的防火墙）只开 22（SSH）和 ICMP（ping），删了 3389（Windows 远程桌面，Linux 用不上）

## 2. 认识机器
```bash
whoami                 # 我是谁（root）
hostname               # 机器名
uname -a               # 内核和系统信息
cat /etc/os-release    # 系统版本（Ubuntu 24.04）
nproc                  # CPU 核数（2）
free -h                # 内存，-h = human-readable，用 G/M 显示
df -h                  # 磁盘
uptime                 # 开机多久、负载
htop                   # 实时看进程（q 退出）
```

## 3. 装软件（apt）
```bash
apt update                              # 刷新软件列表
apt upgrade -y                          # 升级已装的软件，-y = 自动回答 yes
apt install -y tmux git curl htop vim   # 装常用工具
reboot                                  # 更新后提示 System restart required 时重启
```

## 4. Swap（拿硬盘当备用内存，2G 内存必须加）
```bash
fallocate -l 2G /swapfile    # 建一个 2G 的空文件
chmod 600 /swapfile          # 只有 root 能读写
mkswap /swapfile             # 格式化成 swap
swapon /swapfile             # 启用
echo '/swapfile none swap sw 0 0' >> /etc/fstab   # 开机自动启用（>> 追加！一个 > 会把 fstab 覆盖掉）
free -h                      # Swap 那行变成 2.0Gi 就对了
```

## 5. tmux（断线了程序也不停）
```bash
tmux new -s main        # 新建会话 main
# Ctrl+B 松开再按 D     → 离开会话（程序继续跑）
tmux ls                 # 看有哪些会话
tmux attach -t main     # 回到会话
```
- 在 Termius 的 tmux 里复制：按住 Shift 再用鼠标选
- 终端里 Ctrl+C 是「中断程序」，不是复制
- 后来 AstrBot 改成了 systemd 服务，就不用 tmux 挂它了（见第 10 节）

## 6. 文件操作
```bash
mkdir -p ~/projects/playground   # 建目录，-p 连上级一起建
cd ~/projects/playground         # 进入目录（~ = /root）
pwd                              # 我在哪
ls -la                           # 列出所有文件（含隐藏文件）、权限、大小
echo "hello" > note.txt          # 写入（覆盖）
echo "second" >> note.txt        # 追加
cat note.txt                     # 看内容
nano note.txt                    # 编辑：Ctrl+O 回车保存，Ctrl+X 退出
cp note.txt backup.txt           # 复制
mv backup.txt old.txt            # 移动/改名
rm old.txt                       # 删除（没有回收站！）
tail -f xxx.log                  # 实时看日志最后几行
grep -n 关键词 文件               # 在文件里搜
```
**权限 `-rw-r--r--` 怎么看**：第 1 位是类型（- 文件 / d 目录），后面三组分别是 所有者/同组/其他人 的 读r 写w 执行x。
`chmod 600 文件` = 只有自己能读写（放密码的文件都这样）；`chmod 700 目录` = 只有自己能进。

## 7. 安全：fail2ban
```bash
journalctl -u ssh --since today | grep -c "Failed password"   # 今天被试了多少次密码
apt install -y fail2ban
systemctl enable --now fail2ban        # 开机自启并马上启动
fail2ban-client status sshd            # 看封了哪些 IP
```

## 8. Docker
```bash
apt install -y docker.io               # 装 Docker
nano /etc/docker/daemon.json           # 配镜像加速：{"registry-mirrors": ["https://xxx.mirror.aliyuncs.com"]}
systemctl restart docker
docker run hello-world                 # 第一个容器
docker run -d --name web -p 8080:80 nginx   # 后台跑 nginx，把服务器 8080 映射到容器 80
docker ps        /  docker ps -a       # 运行中的 / 全部容器
docker logs web                        # 看容器日志
docker stop web && docker rm web       # 停止、删除容器
docker images                          # 本地镜像（我们有 nginx、hello-world）
docker run -d -p 8080:80 -v /root/site:/usr/share/nginx/html nginx   # 数据卷：把服务器目录挂进容器
systemctl stop docker docker.socket    # 不用时停掉省内存（现在就是停着的）
```
概念：**镜像**=安装包，**容器**=跑起来的实例，**端口映射** `-p 外:内`，**数据卷** `-v 外:内`（容器删了数据还在）。

## 9. 网络
- **公网 IP** <服务器公网IP>：全世界都能找到；**私网 IP** 172.x：只在阿里云内部
- 想从外面访问服务器上的某个端口：程序要监听 `0.0.0.0`，**而且**安全组要放行这个端口
- **SSH 隧道**（不开放端口也能访问服务器上的服务）：
```powershell
ssh -N -L 16185:127.0.0.1:6185 ecs     # 电脑的 16185 → 加密通道 → 服务器的 127.0.0.1:6185
```
然后浏览器开 `http://127.0.0.1:16185`。我们用它进 AstrBot 后台，后台不对公网开放更安全。
```bash
ss -ltnp                               # 服务器上哪些程序在监听哪些端口
curl -I http://127.0.0.1:6185          # 在服务器上测一个端口通不通
```

## 10. systemd（让程序常驻、开机自启、崩了自动重启）
```bash
nano /etc/systemd/system/astrbot.service   # 写服务文件（WorkingDirectory、ExecStart、Restart=on-failure）
systemctl daemon-reload                    # 改了服务文件后重新加载
systemctl enable --now astrbot             # 开机自启 + 马上启动
systemctl status / restart / stop astrbot
journalctl -u astrbot -f                   # 实时日志
journalctl -u astrbot --since -1h | grep ERRO
```

## 11. cron（定时跑脚本）
```bash
cat /etc/cron.d/dafeiyu-images
# 17 */4 * * * root python fetch_images.py   ← 分 时 日 月 星期 用户 命令：每 4 小时的第 17 分钟
timedatectl                                  # 系统时区（服务器是 Asia/Shanghai，所以 cron 按北京时间）
```

## 13. 在电脑上传文件 / 远程执行
```powershell

```

## 14. 部署 AstrBot 的完整步骤（回顾）
1. `uv tool install astrbot`，在 `/root/astrbot` 目录下 `astrbot run` 初始化（**一定在这个目录下**）
2. 写 systemd 服务，WorkingDirectory=/root/astrbot，`systemctl enable --now astrbot`
3. 开隧道进后台：接 DeepSeek（模型提供商）→ 人格设定 → QQ 官方机器人（一键扫码）
4. 系统设置时区改 Europe/Berlin；未来任务里建定时聊天
5. 接 MCP：`/root/astrbot/data/mcp_server.json` 里加 dafeiyu → 重启
6. 备份：服务器 cron 打包 + 电脑 Windows 任务计划下载


## 15. 大肥鱼日常运维命令（速查）
**验收和体检**（都是只读，随便跑）：
```bash
bash /root/dafeiyu-mcp/acceptance.sh       # 验收：23 项 [PASS]/[WARN]/[FAIL]，30 秒
bash /root/dafeiyu-mcp/healthcheck.sh      # 体检：服务、资源、cron、图库、备份、定时任务、报错、每个工具冒烟测试
```
**大肥鱼本体**：
```bash
systemctl status astrbot                   # 在不在跑
systemctl restart astrbot                  # 重启（改了 server.py / 配置后必须）
journalctl -u astrbot -f                   # 实时日志
journalctl -u astrbot --since -1h | grep ERRO              # 最近一小时报错
journalctl -u astrbot --since -1h | grep 'Message sent'    # 最近一小时发出了几条消息
```
**看门狗**：
```bash
tail -20 /root/dafeiyu-mcp/watchdog.log           # 最近修了什么
cat /root/dafeiyu-mcp/watchdog_state.json         # 心跳、补发记录、自身错误
/root/.local/share/uv/tools/astrbot/bin/python /root/dafeiyu-mcp/watchdog.py   # 手动巡检一次
mv /etc/cron.d/dafeiyu-watchdog /root/            # 暂停（移回去恢复）
```
**邮件**：
```bash
tail /root/dafeiyu-mcp/mail_check.log             # 门铃什么时候叫醒过大肥鱼 / 跳过了广告
cd /root/dafeiyu-mcp && /root/.local/share/uv/tools/astrbot/bin/python mail_check.py --force   # 立刻检查一次
mv /etc/cron.d/dafeiyu-mail /root/                # 暂停邮件推送
```
```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Desktop\set-mail.ps1"   # 电脑上：配置/改邮箱密码
```
**数据和备份**：
```bash
astrbot-backup                                    # 手动备份一次
ls -lt /root/backups | head                       # 看备份
cd /root/dafeiyu-mcp && /root/.local/share/uv/tools/astrbot/bin/python ncm_login.py   # 网易云重新扫码登录
ls /etc/cron.d/                                   # 所有系统定时任务
```
**直接试一个工具**（不经过 AI）：
```bash
cd /root/dafeiyu-mcp && /root/.local/share/uv/tools/astrbot/bin/python -c "import server; print(server.server_status())"
```
> ⚠️ 不要这样直接调 `new_emails()`：它会推进“已读位置”，真邮件就不会推给你了。要看邮箱用 `server._mail_scan(advance=False)`。

## 16. 出问题时按这个顺序查
1. 服务器日报哪里红 → 对应 `03-运维手册.md` 的那一节
2. `bash acceptance.sh` → 看哪项 FAIL
3. `journalctl -u astrbot --since -1h | grep ERRO` → 看报错
4. `tail watchdog.log` → 看门狗有没有修过、修没修好
5. 还不行 → `systemctl restart astrbot`，再跑一次 `acceptance.sh`
