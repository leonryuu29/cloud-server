# 运维手册（常用操作）

## 连接
```powershell
ssh ecs                                   # 登录服务器（电脑上配好了密钥，别名 ecs）
ssh -N -L 16185:127.0.0.1:6185 ecs        # 开隧道，浏览器打开 http://127.0.0.1:16185 进 AstrBot 后台
```
- 也可以用 Termius（同一台机器）；Termius 的 Port Forwarding 建 Local 16185 → 127.0.0.1:6185
- 关掉隧道/终端只影响网页后台，**不影响大肥鱼**
- 6185 是服务器上 AstrBot 的端口，16185 是电脑上的隧道入口（避开本机 AstrBot 的 6185）

## AstrBot
```bash
systemctl status astrbot          # 状态
systemctl restart astrbot         # 重启（改了配置/MCP 代码后）
journalctl -u astrbot -f          # 实时日志（Ctrl+C 退出）
journalctl -u astrbot --since -1h | grep ERRO   # 最近一小时报错
```
- **别在 tmux 里手动 `astrbot run`**（会和服务抢端口、还可能用错数据目录）
- 忘了后台密码：`systemctl stop astrbot && cd ~/astrbot && astrbot password && systemctl start astrbot`

## 大肥鱼工具箱
```bash
bash /root/dafeiyu-mcp/healthcheck.sh     # 全面体检（只读）：服务、资源、cron、图库、备份、定时任务、报错、工具冒烟测试
bash /root/dafeiyu-mcp/acceptance.sh      # 验收（只读，30 秒）：稳定/自动化/送达/自愈/邮件/数据/安全/成本 23 项
cd /root/dafeiyu-mcp && /root/.local/share/uv/tools/astrbot/bin/python ncm_login.py   # 网易云登录过期时重新扫码
```
- 改了 `server.py` 后要 `systemctl restart astrbot` 才生效
- 配置：`/root/dafeiyu-mcp/config.json`（权限 600，里面有邮箱授权码）

## 看门狗（自动修复）
```bash
tail -20 /root/dafeiyu-mcp/watchdog.log           # 它最近修了什么（没修过就是空的）
cat /root/dafeiyu-mcp/watchdog_state.json         # 心跳时间、补发记录、自身错误
/root/.local/share/uv/tools/astrbot/bin/python /root/dafeiyu-mcp/watchdog.py   # 手动巡检一次
```
- 每 10 分钟自动跑一次（`/etc/cron.d/dafeiyu-watchdog`），每次约 0.4 秒、33 MB，跑完就退出
- 会自己做：推送没发出 → 补发 1 次；AstrBot 停了 → 重启；MCP 掉线 → 重启（1 小时最多 1 次）；图库 < 6 → 补货；磁盘 > 90% → 清临时图
- **服务器日报亮红 = 看门狗也没修好**，这时才需要人来看
- 想暂停看门狗：`mv /etc/cron.d/dafeiyu-watchdog /root/`（恢复就移回去）
- 它调 AstrBot 后台接口用的是本机现签的 5 分钟令牌，**不需要也不要**额外建 API Key

## 重要邮件
- 链路：Gmail →（WEB.DE 代收服务，约 2 分钟）→ you@web.de →（邮件门铃 `mail_check.py`，每 10 分钟，德国 7–23 点）→ 大肥鱼「重要邮件」任务 → QQ
- 广告发件人名单在 `mail_check.py` 的 `NOISE_DOMAINS`：只放肯定不重要的（社交、营销）；全是这些就不叫醒大肥鱼
- 配置 / 改密码：电脑上运行 `powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Desktop\set-mail.ps1"`，输入地址和密码 → 服务器先试登录，成功才写进 `config.json`（600）
```bash
tail /root/dafeiyu-mcp/mail_check.log                 # 门铃什么时候叫醒过大肥鱼
cd /root/dafeiyu-mcp && /root/.local/share/uv/tools/astrbot/bin/python mail_check.py --force   # 立刻检查一次（忽略 7–23 点限制）
```
- **不要**在体检/调试里直接调 `new_emails()`：它会推进“已读位置”，真邮件就不推了。只看用 `_mail_scan(advance=False)`
- 暂停邮件推送：`mv /etc/cron.d/dafeiyu-mail /root/`
- 在 WEB.DE 网页里删掉代收服务 = 不再收 Gmail；在设置里关掉 IMAP = 大肥鱼读不到

## 电脑协作（详见 09）
- 电脑上 Codex / Claude 桌面版已注册 `dafeiyu`（MCP over SSH），**改配置后要重启那个应用**
- 看任务队列：`cat /root/dafeiyu-mcp/data/pc_tasks.json`
- 重新注册（重装应用后）：`node T:\云服务器\dafeiyu-mcp\dev-history\register_pc.js`
- 连不上：先在 PowerShell 试 `ssh -o BatchMode=yes ecs echo ok`；能通再看应用的 MCP 日志
- 不想用了：删掉 `config.toml` 里的 `[mcp_servers.dafeiyu]` 段和 Claude 配置里的 `dafeiyu`

## 备份
- 服务器：每周日北京 10:00（德国周日凌晨 3:00）自动打包 `/root/astrbot/data` → `/root/backups`，保留 8 份；手动：`astrbot-backup`
- 电脑：Windows 任务计划「大肥鱼每周备份」每周日 12:00 下载到 `C:\Users\1\Documents\dafeiyu-backup`，保留 12 份
- 备份包里有 API Key，**不要传到公开仓库**
