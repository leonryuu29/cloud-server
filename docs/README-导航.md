## 一、这个项目是什么（30 秒版）
北京一台 2 核 2G 的阿里云服务器上，住着一条叫 **大肥鱼** 的 AI，通过 QQ 跟你聊天，并且**每天自己主动推送**：日报、服务器日报、美图、叫床+课表+天气、问候、网易云品鉴、重要邮件。

它由四个部分组成：

| 部分 | 比喻 | 是什么 | 花不花 token |
|---|---|---|---|
| **AstrBot** | 身体 | 框架：收发 QQ 消息、调 DeepSeek、按时间跑定时任务 | 调 DeepSeek 时花 |
| **DeepSeek** | 大脑 | 模型：理解、判断、说话 | 花 |
| **dafeiyu-mcp** | 手 | 我们手写的 MCP 工具箱：大肥鱼想看什么就调哪个工具（日报、网易云、画廊、服务器状态、邮件） | 工具本身不花，AI 调用它的那一轮花 |
| **看门狗 + 邮件门铃** | 自主神经 | 我们手写的普通 Python 脚本，系统定时叫醒：盯着大肥鱼、坏了就修；邮箱有新信才叫醒它 | **不花** |

一句话原则：**能用代码做的不让 AI 做；AI 只负责“理解”和“说话”。**

## 二、你平时需要做什么
**几乎什么都不用做。** 推送、补货、备份、自我修复、邮件判断都是自动的。

| 情况 | 你要做的 |
|---|---|
| 每天 06:05 收到「服务器日报」 | 看一眼：全绿就不用管；有红灯说明看门狗也没修好 → 找 Claude 看 |
| 网易云登录过期（几个月一次，日报会显示「未登录」） | 服务器上跑 `ncm_login.py` 扫码 |
| WEB.DE 密码改了 | 电脑上跑桌面的 `set-mail.ps1` |
| 换学期 / 课表变了 | AstrBot 后台改人格里的课表 |
| 想全面检查一下 | `ssh ecs` → `bash /root/dafeiyu-mcp/acceptance.sh`（30 秒，只读） |
| 在外面想让电脑做件事 | QQ：「让电脑上的 Claude 帮我……」；回到电脑前打开 Codex/Claude 说「看看大肥鱼派的任务」 |
| 阿里云账户 | 别欠费 |

## 四、最常用的 8 条命令
在电脑 PowerShell 里：
```powershell
ssh ecs                                    # 登录服务器
ssh -N -L 16185:127.0.0.1:6185 ecs         # 开隧道 → 浏览器打开 http://127.0.0.1:16185 进 AstrBot 后台
```
登录服务器后：
```bash
bash /root/dafeiyu-mcp/acceptance.sh       # 验收：23 项，稳定/自动化/送达/自愈/邮件/数据/安全/成本
bash /root/dafeiyu-mcp/healthcheck.sh      # 体检：更细的原始信息 + 每个工具冒烟测试
systemctl restart astrbot                  # 重启大肥鱼（改了代码/配置后）
journalctl -u astrbot --since -1h | grep ERRO   # 最近一小时报错
tail /root/dafeiyu-mcp/watchdog.log        # 看门狗最近修了什么
tail /root/dafeiyu-mcp/mail_check.log      # 邮件门铃最近叫醒过大肥鱼几次
```
更多命令：`docs/03-运维手册.md`、`docs/04-学习笔记-命令大全.md` 第 15 节。

## 五、一天是怎么自动转起来的（德国时间）
```
每 10 分钟  看门狗巡检（没发出的推送补发、挂了重启）  ·  邮件门铃看一眼 WEB.DE（7–23 点）
每 4 小时   图库补货
03:00 周日  服务器打包备份  →  12:00 电脑自动下载备份
06:00 日报 → 06:05 服务器日报 → 06:30/06:45/07:00 美图 → 07:20 叫床+课表+天气
12:00 午饭 · 15:00 下午 · 20:00 晚饭 · 23:05 网易云两张卡 · 23:10 听歌快照 · 00:00 晚安
随时        Gmail 来了重要邮件 → 约 2 分钟到 WEB.DE → ≤10 分钟门铃 → 大肥鱼判断 → QQ
```
